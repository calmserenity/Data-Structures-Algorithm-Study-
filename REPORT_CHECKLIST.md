# Report Checklist

## Cover page

- [ ] Course name and code
- [ ] Assignment title
- [ ] Group name or number
- [ ] Student names and IDs

## Introduction

- [ ] Overview of all three problems
- [ ] Reason for selecting each algorithm
- [ ] Python version and tools used

## For each problem

- [ ] Problem description
- [ ] Explanation of the algorithmic method
- [ ] Input and output design
- [ ] Important code snippets
- [ ] Screenshots of sample runs
- [ ] Strengths and limitations
- [ ] Multiple test cases
- [ ] Expected output versus actual output
- [ ] Explanation of how correctness was checked

## Final sections

- [ ] Testing and Validation
- [ ] Challenges and Solutions
- [ ] Declaration of AI Usage
- [ ] Conclusion
- [ ] References
- [ ] Appendices, if needed

## Submission package

- [ ] Report is no more than 15 pages, excluding references and appendices
- [ ] All source files have meaningful filenames
- [ ] README contains correct running instructions
- [ ] Sample inputs and outputs are included
- [ ] Programs run without external packages
- [ ] Final report and source folder are placed in one ZIP file
