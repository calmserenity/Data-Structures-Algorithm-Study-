Problem 2

0/1 Knapsack using Dynamic Programming

Choose items with the highest possible total value without exceeding the weight capacity. “0/1” means each item is either selected once or not selected.

Item Weight Value
Item A310

What does one DP cell mean? DP[i][w] is the best value possible using the first i items with capacity w.
What choice does it make? Compare the value from excluding the current item against including it, when it fits.

The rule used for every cell

DP[i][w] = max(exclude item, include item + earlier best value)

  3. 3

Final answer: select Item A and Item B. Total weight is 7 and maximum value is 22.

Problem 3

Travelling Salesman using a Genetic Algorithm

Find a short route that starts at a distribution depot, visits every package-delivery stop once, and returns to the depot. A genetic algorithm searches for a good route, but it does not guarantee the mathematical optimum for every input.

How one route is represented

[0, 3, 2, 1, 4]

This means:

Distribution Depot → Package C → Package B → Package A → Package D → Distribution Depot

The program adds every edge distance, including the final return from Package D to the distribution depot.

The genetic cycle

Create population→ Select parents→ Crossover→ Mutation→ Elitism
  1. 1

    Create random routes. Fisher-Yates shuffling produces valid permutations of the delivery-point indexes.

  2. 2

    Select shorter parents. Tournament selection compares several routes and chooses the shortest.

  3. 3

    Create children. Ordered crossover combines the parents without duplicating or losing delivery points.

  4. 4

    Add variation. Swap mutation may exchange two delivery-point positions.

  5. 5

    Keep the best. Elitism copies the shortest route into the next generation so progress is not lost.

Default sample: population 60, generations 150, mutation rate 0.10, seed 2103. The reproducible route above has total distance 15.00.

How to explain it to your lecturer

Knapsack stores the best value for every smaller item-and-capacity problem. Each cell compares including and excluding the current item, and backtracking finds the selected items.
The TSP genetic algorithm improves a population of route permutations using selection, crossover, mutation, and elitism. It finds a good route efficiently but may not find the global optimum.
